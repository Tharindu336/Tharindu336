<summary>About the numbers &amp; animation</summary>

The original dark yellow tech stack includes the 18 tool icons and real language meters.

Tech meters and contributions use a timestamped public GitHub snapshot, refreshed by the included Actions workflow every six hours once uploaded and enabled. Language percentages represent code bytes in owned public repositories, excluding forks and notebooks; they are not skill ratings. Streaks and the calendar cover the displayed 365 days.

The view badge is a shared [image-view counter](https://github.com/antonkomarev/github-profile-views-counter), not a count of unique visitors. GitHub caching can delay updates. The website has a separate server-backed view tracker: totals stream between connected pages, with daily history and a connection indicator. Browser history and active time remain local. The live tracker requires the included Node server; GitHub Pages serves static files only.

The Snake GIF is an animated preview. GitHub displays the animation directly. The companion website also includes a playable Snake arena. Player mode supports keyboard, swipe and touch buttons, with linked portals, shields, slow time, combos and speed levels. AI demo scores never overwrite a player's record.

All five local artwork files sit beside this README. Upload the complete repository or the ready-to-upload package, including those images. [Setup and controls](./PROFILE.md).
